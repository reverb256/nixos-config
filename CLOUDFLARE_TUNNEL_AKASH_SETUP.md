# Cloudflare Tunnel Setup for Akash Provider
**Generated**: 2026-03-18 05:05 UTC

## Overview
Use Cloudflare Tunnel to securely expose Akash provider without exposing public IP.

## Benefits
- ✅ No public IP exposed (home IP stays private)
- ✅ No firewall port forwarding needed
- ✅ Automatic HTTPS/TLS termination
- ✅ DDoS protection via Cloudflare
- ✅ Easier setup (no router configuration)

## Setup Instructions

### Step 1: Create Tunnel in Cloudflare Dashboard

1. Go to: https://dash.cloudflare.com/reverb256.ca/access/tunnels
2. Click **"Create Tunnel"**
3. Select: **"Cloudflare Tunnel"**
4. Name: `akash-provider`
5. **Choose your environment**: Select **"Standalone"** or **"Docker"**
6. Click **"Save Tunnel"**
7. **Copy the Tunnel Token** (shown only once!)

### Step 2: Install Tunnel Token

Save the tunnel token to agenix secret:

```bash
cd /etc/nixos/secrets
agenix -e cloudflared-token.age
# Paste the tunnel token when prompted
# Format: {"AccountID":"xxx","TunnelID":"xxx","TunnelSecret":"xxx"}
```

### Step 3: Configure NixOS Module

Add to `/etc/nixos/hosts/zephyr/configuration.nix`:

```nix
{config, pkgs, ...}: {
  services.cloudflared-tunnel = {
    enable = true;
    tunnelId = "YOUR_TUNNEL_ID_HERE";  # From Cloudflare dashboard

    ingressRules = [
      # Provider bid engine
      {
        hostname = "provider.reverb256.ca";
        service = "http://localhost:8443";
      }
      # Tenant ingress (catch-all for deployments)
      {
        hostname = "*.ingress.reverb256.ca";
        service = "http://localhost:80";
      }
      # Fallback
      {
        hostname = "ingress.reverb256.ca";
        service = "http://localhost:80";
      }
    ];
  };
}
```

### Step 4: Add DNS Records in Cloudflare

```
Type: CNAME
Name: provider
Content: <your-tunnel-id>.cfargotunnel.com
Proxy: DNS only (grey cloud icon)
TTL: Auto

Type: CNAME
Name: ingress
Content: <your-tunnel-id>.cfargotunnel.com
Proxy: DNS only (grey cloud icon)
TTL: Auto
```

### Step 5: Update Akash Provider ConfigMap

```bash
kubectl patch cm akash-provider-main -n akash-provider --type=json \
  -p='[{"op": "replace", "path": "/data/AKASH_CLUSTER_PUBLIC_HOSTNAME", "value":"provider.reverb256.ca"}]'

kubectl patch cm akash-provider-main -n akash-provider --type=json \
  -p='[{"op": "replace", "path": "/data/AKASH_DEPLOYMENT_INGRESS_DOMAIN", "value":"ingress.reverb256.ca"}]'

kubectl delete pod akash-provider-0 -n akash-provider
```

## Troubleshooting

### Tunnel Not Starting
```bash
# Check logs:
journalctl -u cloudflared-tunnel -f

# Verify token:
cat /run/agenix/cloudflared-token.json | jq .
```

### DNS Not Resolving
```bash
# Check Cloudflare DNS:
dig provider.reverb256.ca
dig ingress.reverb256.ca

# Verify CNAME points to tunnel
dig +short CNAME provider.reverb256.ca
```

### Provider Not Reachable
```bash
# Check tunnel routes:
curl -v http://localhost:8443/healthz
# Should work locally

# Check firewall (should be empty with tunnel):
sudo ufw status
```
