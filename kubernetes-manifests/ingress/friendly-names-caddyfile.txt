# All cluster services accessible via *.cluster.local
#
# NAMING CONVENTION:
# - service.cluster.local → Kubernetes service
# - app.zephyr.cluster.local → Systemd service on specific host
# - category.cluster.local → Group of related services
#
# UPDATE INSTRUCTIONS:
# 1. Add route to this Caddyfile
# 2. Optionally: add service deployment to k8s/
# 3. Apply: kubectl apply -f 02-configmap.yaml
# 4. Restart: kubectl -n ingress-system rollout restart daemonset/caddy-ingress
