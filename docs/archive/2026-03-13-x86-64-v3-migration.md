# x86-64-v3 Microarchitecture Migration Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Migrate 4-node NixOS cluster from baseline x86-64 to x86-64-v3 microarchitecture level to enable SIMD performance improvements.

**Architecture:** Nexus-first build strategy leveraging Harmonia cache, with baseline specialisation fallback on each node. Each node validates for 5 days before removing fallback.

**Tech Stack:** NixOS flakes, Colmena deployment, Harmonia local cache, systemd specialisations

## Task 2: Update flake.nix for v3 Support

**Files:**
- Modify: `/etc/nixos/flake.nix:74-131`

**Step 1: Read current flake.nix structure**

Run: `cat /etc/nixos/flake.nix | head -80`
Expected: Understand current `mkNixosSystem` helper

**Step 2: Add v3 system configuration**

Edit `/etc/nixos/flake.nix`, add after line 79:

```nix
    # ========================================================================
    # x86-64-v3 MICROARCHITECTURE VARIANT
    # ========================================================================
    # All cluster CPUs support AVX2 and v3 requirements:
    # - Zephyr: Ryzen 9 5950X (Zen 3)
    # - Nexus: Ryzen 9 3900X (Zen 2)
    # - Forge: i5-9500 (Coffee Lake)
    # - Sentry: Ryzen 7 1700 (Zen 1, has AVX2)
    #
    # Benefits: 10-30% SIMD performance uplift for AI, mining, crypto
    # Cost: No binary cache compatibility (must build from source)
    # ========================================================================
    systemV3 = "x86_64-linux";  # Same system triple, different gcc arch

    # v3-optimized package set
    pkgsV3 = import nixpkgs {
      inherit systemV3;
      localSystem = {
        system = systemV3;
        gcc.arch = "x86-64-v3";
      };
      config.allowUnfree = true;
    };

    # Helper to build v3 NixOS system
    mkNixosSystemV3 = {
      hostName,
      extraModules ? [],
    }:
      nixpkgs.lib.nixosSystem {
        system = systemV3;
        specialArgs = {
          inherit inputs pkgsV3;
        };
        modules =
          commonModules
          ++ [
            ./hosts/${hostName}/configuration.nix
            {nixpkgs.hostPlatform.gcc.arch = "x86-64-v3";}
            {nixpkgs.config.allowUnsupportedSystem = true;}
          ]
          ++ extraModules;
      };
```

**Step 3: Add v3 host definitions**

Edit `/etc/nixos/flake.nix`, modify hosts section (around line 136):

```nix
    # ========================================================================
    # HOST DEFINITIONS - Single source of truth
    # ========================================================================
    hosts = {
      zephyr = {hostName = "zephyr";};
      nexus = {hostName = "nexus";};
      forge = {hostName = "forge";};
      sentry = {hostName = "sentry";};
    };

    # ========================================================================
    # x86-64-v3 HOST DEFINITIONS (migration target)
    # ========================================================================
    hostsV3 = {
      zephyr = {hostName = "zephyr";};
      nexus = {hostName = "nexus";};
      forge = {hostName = "forge";};
      sentry = {hostName = "sentry";};
    };
```

**Step 4: Add v3 nixosConfigurations output**

Edit `/etc/nixos/flake.nix`, add after line 149:

```nix
    # ========================================================================
    # OUTPUT 1.5: nixosConfigurationsV3 (x86-64-v3 microarchitecture)
    # ========================================================================
    nixosConfigurationsV3 =
      builtins.mapAttrs
      (_name: value: mkNixosSystemV3 {inherit (value) hostName;})
      hostsV3;
```

**Step 5: Verify flake syntax**

Run: `nix flake check`
Expected: No errors

**Step 6: Commit flake.nix changes**

Run:
```bash

- Added pkgsV3 with gcc.arch = x86-64-v3
```

## Troubleshooting Guide

### Build fails on package X

**Symptom:** Build error during Nexus v3 build

**Diagnosis:** Check if package has hardcoded architecture assumptions

**Solution:**
1. Note the failing package
2. Check if nixpkgs has an issue filed
3. Consider overlay with patch or skip package temporarily

### Service won't start after v3 migration

**Symptom:** Systemd service in failed state after reboot

**Diagnosis:** Check service logs

**Solution:**
```bash
ssh $host "journalctl -u $service -xe"
```
If critical issue: Reboot to baseline specialisation

### Performance regression

**Symptom:** Workloads slower after v3 migration

**Diagnosis:** Compare benchmarks

**Solution:**
1. Verify AVX2 is actually being used: `grep avx2 /proc/cpuinfo`
2. Check package rebuild: `nix path-info -S /run/current-system`
3. If regression confirmed: Revert to baseline, investigate

### Harmonia cache full

**Symptom:** Disk space warning on Nexus

**Diagnosis:** `ssh j_kro@nexus "df -h /var/lib/harmonia"`

**Solution:**
```bash
ssh j_kro@nexus "sudo nix-store --gc --max-freed $(($(df --output=avail /var | tail -1) * 1024))"
```
