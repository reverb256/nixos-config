## 4. Issues Found

### ❌ CRITICAL: Missing Metrics Server

**Impact**: **HIGH** - Horizontal Pod Autoscaling (HPA) broken across cluster

**Affected Services**:
- `opencode-hpa` (ai-coding namespace)
- `claude-code-hpa` (ai-coding namespace)
- `istiod` (istio-system namespace)
- `ai-gateway-hpa` (ai-inference namespace)

**Error Pattern**:
```
failed to get cpu utilization: unable to fetch metrics from resource metrics API:
the server could not find the requested resource (get pods.metrics.k8s.io)
```

**Root Cause**: Metrics server not installed in `kube-system` namespace

**Impact**:
- HPAs cannot scale pods based on CPU/memory
- Autoscaling is non-functional
- Manual scaling required

**Fix Required**:
```bash
# Install metrics-server (manifest varies by Kubernetes version)
kubectl apply -f https://github.com/kubernetes-sigs/metrics-server/releases/latest/download/components.yaml

# Or via helm:
helm install metrics-server metrics-server/metrics-server -n kube-system
```

**Priority**: **HIGH** - Affects cluster autoscaling capabilities
