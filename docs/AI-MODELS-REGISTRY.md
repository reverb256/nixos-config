# Unified AI Models Registry

**Last Updated:** 2026-05-21  
**Status:** Operational  
**Grade:** B+ → A (after unified registry implementation)

## Overview

The Unified AI Models Registry is the single source of truth for all AI model and provider configurations across the sovereign AI cluster. It consolidates scattered configurations from OpenCode, Claude Code, Hermes Agent, and other tools into one declarative, manageable location.

## Architecture

### Core Components

1. **`/etc/nixos/ai-models.toml`** - Single source of truth
2. **`/etc/nixos/modules/ai-models.nix`** - NixOS module integration
3. **`/etc/nixos/scripts/validate-ai-models-registry.py`** - Registry validator
4. **Tool-specific config generators** - Consumes registry via `ai-coding-tools` module

### Registry Structure

```toml
[defaults]
primary = "nvidia/nemotron-3-nano-30b-a3b"
fallback = "google/gemma-2b"

[models]
# Model definitions with full names, capabilities, and backend references

[backends]
# Provider configurations with priority, URLs, and available models
```

## Integration Points

### Current Consumers

1. **OpenCode** (`~/.opencode/config.json`)
   - Z.AI, NVIDIA NIM, OpenCode Go, LM Studio, llama.cpp
   - Generated by `ai-coding-tools.opencode.nix`

2. **Claude Code** (`~/.claude/settings.json`)
   - ANTHROPIC_BASE_URL → AI Gateway
   - MCP servers for k8s, git, github, etc.

3. **Hermes Agent** (`~/.hermes/config.yaml`)
   - Multiple providers with fallback chains
   - Model aliases for easy switching

4. **AI Gateway** (`ai-inference-gateway`)
   - Routes to local/external models based on availability
   - Implements the priority strategy

### Usage Pattern

```yaml
# Tool config generation (NixOS module)
ai-coding-tools:
  zaiProvider:
    url: ${ai-models.backends.zai.url}
    models: 
      - ${ai-models.models.zai-glm-5-1.name}
      - ${ai-models.models.zai-glm-4-7.name}
```

## Validation

### Running the Validator

```bash
# Basic validation
python3 scripts/validate-ai-models-registry.py

# With consumer config checks
python3 scripts/validate-ai-models-registry.py --check-consumers

# Verbose output
python3 scripts/validate-ai-models-registry.py --verbose
```

### Validation Phases

1. **Structure Validation** - TOML parse, required sections
2. **Model Validation** - Required fields, backend cross-references
3. **Consumer Validation** - Cross-reference with actual tool configs

## Maintenance

### Adding a New Model

1. Add model definition to `[models]` section
2. Add backend configuration to `[backends]` section (if new)
3. Update model's `backends` array to reference the backend
4. Run validator to check consistency
5. Update consumer configs via `ai-tools-regenerate`

### Adding a New Consumer

1. Add consumer config generator to `modules/development/ai-coding-tools/`
2. Reference model registry via `config.ai-models`
3. Update validator to check new consumer config
4. Test with `ai-tools-regenerate`

### Schema Changes

When modifying registry structure:

1. Update `REQUIRED_SECTIONS` in validator
2. Update `ai-models.nix` NixOS module
3. Update consumer generators
4. Test validator thoroughly
5. Update documentation

## Troubleshooting

### Common Issues

**Model not found:**
- Check model name matches exactly (case-sensitive)
- Verify backend exists and is defined
- Run validator: `python3 scripts/validate-ai-models-registry.py`

**Backend unreachable:**
- Check URL in `[backends]` section
- Verify network connectivity
- Check host node is accessible

**Consumer config stale:**
- Run `ai-tools-regenerate`
- Check `systemctl status ai-coding-tools-config`
- Restart systemd service: `sudo systemctl restart ai-coding-tools-config`

### Validation Errors

| Error | Meaning | Fix |
|-------|---------|-----|
| `Missing required section` | TOML structure incomplete | Add missing section |
| `Missing 'name' field` | Model definition incomplete | Add required fields |
| `References non-existent backend` | Model references undefined backend | Add backend or fix reference |
| `References non-existent model` | Default references missing model | Fix default or add model |
