# GPU Workload Module Consolidation

## What belongs here

Shared shell library and per-node PSI threshold configuration for the GPU workload management system. All runtime services (gaming-detection, gpu-profiles, mining-coordinator) source the shared library for common functions.

## State Directory

All state files live in `/run/gpu-workload/`:
- `gaming_state` -- written by gaming-detection, read by mining-coordinator + gpu-profiles
- `profile_request` -- written by mining-coordinator, read by gpu-profiles
- `ai-state` -- written by external AI inference gateway, read by gpu-profiles
- `thresholds.conf` -- generated by psi-profiles, read by mining-coordinator

## Testing

Run `nix flake check` from `/etc/nixos` to validate all module changes.
